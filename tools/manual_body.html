講師課堂小幫手・操作手冊

抽籤點名、隨機分組、計時器、搶答器、匿名即時投票，一個網頁投影上課就能用。
← 回到工具

這是什麼上課前準備抽籤點名隨機分組計時器搶答器即時投票測驗手機連線原理快捷鍵常見問題隱私與限制關於創作者

這是什麼

上課時常用的五個小工具放在同一頁，畫面是黑板（也可以換白板），字很大，適合接投影機。

  • 🎯 抽籤點名：從名單抽人回答問題，可設定抽過的不再抽。
  • 👥 隨機分組：指定分幾組或每組幾人，人數最多只差 1 人，可順便抽組長。
  • ⏱ 計時器：倒數（討論、小考）和碼表，最後 10 秒變紅，時間到會響。
  • 🔔 搶答器：現場按鍵（鍵盤或觸控螢幕）或學生用手機搶答，有犯規判定和計分。
  • 🗳 即時投票：學生掃 QR code 用手機作答，大螢幕即時顯示長條圖（意見調查，不計分）。
  • 📝 測驗：匯入題庫手動或自動出題，記名計分，下載每位學生每題答對或答錯的成績清單。

不用註冊、不用安裝。名單只存在老師這台電腦。

上課前準備：班級名單

  1. 按右上角「📋 名單」。
  2. 上傳檔案：按「📂 上傳 CSV／Excel」，選有「學號」「姓名」欄的 .xlsx 或 .csv（校務系統匯出的名單通常就可以）。沒有標題列也會依內容自動判斷哪一欄是學號；台灣 Excel 存的 Big5 編碼 CSV 也讀得懂。舊版 .xls 請先在 Excel「另存新檔」成 .xlsx 或 CSV。
  3. 或直接貼上：一行一位，「學號 姓名」或只有姓名都可以；從 Excel 複製學號、姓名兩欄貼上也行。
  4. 「投影時顯示」可以選姓名、學號＋姓名，或只顯示學號（不想讓真名出現在投影上時用）。
  5. 下載名單：「⬇ 下載 CSV」「⬇ 下載 Excel」，內容有學號、姓名、今天出席，分過組或抽過籤也會附上組別與抽籤順序。下載的檔案也可以當範本，改完再上傳。
  6. 沒有名單或不想輸入真名，可以按「產生 1～N 號」，用座號代替。
  7. 可以建好幾個班級，上課時在右側下拉選單切換。

上課時點名單裡的名字可以標示「今天缺席」，缺席的人不會被抽到也不會被分組；下次上課按「全部出席」恢復。

名單只存在這台電腦的瀏覽器。換電腦上課前，到「⚙ 常用設定 → 資料備份」下載備份檔，再到教室電腦還原。

🎯 抽籤點名

  • 按「🎯 抽籤」或空白鍵，名字會在黑板上快速跳動後停下來。
  • 「一次 N 人」可以一次抽多位（最多 10 位）。
  • 勾「抽過的不再抽」：抽過的人會放到右邊「已抽出」，直到按「↺ 重新開始」。點已抽出的名字可以放回籤筒（例如他剛好去洗手間）。
  • 不勾的話，每次都從全部出席的人裡抽，可能重複抽到同一人。

👥 隨機分組

  • 選「分成幾組」或「每組幾人」，按「🎲 分組」或空白鍵。
  • 除不盡時，各組人數最多只差 1 人（例如 23 人分 4 組＝6、6、6、5）。
  • 勾「每組抽一位組長」，每組第一位會標上 ★組長。
  • 「📋 複製結果」可以貼到 LINE 群組或教學平台。結果會保留到下次分組。

⏱ 計時器

倒數

  • 點右邊快速設定（30 秒～30 分）或自訂分秒，按「▶ 開始」或空白鍵。
  • 計時中可以按「＋1 分／−1 分」臨時加減時間。
  • 剩 1 分鐘（或剩四分之一）數字變黃，最後 10 秒變紅並跳動；可勾選「最後 5 秒嗶聲」。
  • 時間到會響鈴，數字閃爍並開始顯示超時多久（＋00:12）。按「✔ 知道了」回到原本的時間。

碼表

開始／暫停／分段，分段時間列在右邊。適合計算報告時間。

切換到其他工具時計時不會停，右上角會出現黃色小標顯示剩餘時間，點它就回到計時器。

🔔 搶答器

🖥 現場按鍵（最公平）

  1. 設定 2～6 隊，可以改隊名。
  2. 按「▶ 開始搶答」或空白鍵，黑板顯示「3、2、1」後出現「搶答！」。
  3. 各隊按自己的數字鍵 1～6，或直接按螢幕上的色塊（觸控螢幕、互動白板）。
  4. 最快的隊伍放大顯示，後面依序列出慢了幾秒。
  5. 倒數期間先按＝犯規，這一輪不能搶。
  6. 每隊下方有 ＋／− 計分。

📱 手機搶答

  1. 先「開放手機連線」（見下方即時投票），學生掃 QR code。
  2. 學生加入時輸入的學號或姓名，會依班級名單對應後顯示在大螢幕（跟著「投影時顯示」設定，可以只顯示學號）。
  3. 老師按「開始搶答」，倒數結束時手機才出現大紅鈕「搶！」。
  4. 大螢幕依收到的順序列出名字和相差秒數。
手機搶答的先後以老師電腦收到的時間為準，同學的網路快慢會影響結果，比較適合熱鬧、不計分的場合。

🗳 匿名即時投票

1. 開放手機連線

按右側「📱 開放手機連線」，畫面會出現 6 碼代碼和 QR code。學生用手機相機掃描就能進入作答頁，不用下載 App、不用登入。也可以打開網站自己輸入代碼。

還沒出題時，大黑板上會顯示大大的 QR code，方便全班一起掃。右上角綠色小標顯示目前連線人數。

學生掃描進來第一步要輸入學號或姓名（會記住，右上角 👤 可以改）。老師右側「👥 已加入」會顯示人數，按「看名單」比對班級名單：已加入、名單外（可能打錯字）、還沒加入，可以下載點名 CSV。

🚪 關閉教室：下課按「關閉教室」，在線的學生手機會顯示「教室已關閉」，這個代碼的網址與 QR code 從此失效；下次開放手機連線一定是新代碼。只有同一個分頁重新整理會沿用原本的代碼（學生不用重掃）。「換代碼」也會把舊教室關掉。老師沒開著的教室，學生用舊連結進來會看到「教室已關閉或還沒開放」。同一個瀏覽器開兩個分頁帶兩班，第二個分頁會自動拿到不同代碼，兩班的題目、紀錄、成績各自分開。

🏫 教室名稱與教室大廳

連線卡可以填「教室名稱」（例如「三年甲班 AI 課」，最多 20 字），名稱會顯示在大黑板的 QR code 上方。勾「公開在首頁教室大廳」再按「🏷 儲存名稱」，這間教室就會出現在主頁頂列的「🏫 N 間教室」裡。

學生打開網站按「🎓 學生登入」（或直接開 ?join），會看到目前公開的教室清單（名稱、要不要密碼、幾個人）；點教室、輸入密碼就進去，不用記代碼。也可以照舊輸入 6 碼代碼。

  • 大廳每 20 秒更新一次。教室關閉、所有人離開，或老師離線超過 15 分鐘，就會從大廳消失。
  • 大廳只顯示名稱與人數，不會顯示密碼。公開的教室請一定設密碼，否則任何打開網站的人都進得去。
  • 不想被看到的教室就不要勾「公開」，學生照樣可以用 QR code 或代碼加入。
  • 名稱含不適合的字詞不會公開，畫面會提示。

🔒 教室密碼（選填）

連線卡下方可以設最多 8 位英數字的密碼。掃 QR code 或點連結會自動帶入密碼；自己輸入代碼的人才需要輸入密碼，打錯就進不去。改密碼後，已經加入的學生要重新輸入。代碼被傳到班外時很有用。

按「▶ 開始投票」。題目和選項文字會同步到學生手機（題目最多約 54 字、每個選項約 22 字，太長會截短，完整內容看大螢幕）。

3. 投票中

  • 長條圖即時跳動，顯示票數與百分比、已作答人數。
  • 「🙈 隱藏結果」：先不公布，避免大家跟著多數選；黑板只顯示已作答人數。
  • 學生截止前可以改答案，同一支手機重新整理不會重複計票。
  • 「⏹ 截止」後就不再收票；「▶ 重新開放」可以再開。
  • 「✔ 設定答案」：截止後學生手機會顯示「答對了／再接再厲」和正確答案。
  • 「✋ 舉手計票」：教室沒網路時，每個選項旁邊出現 ＋／−，請學生舉手由老師手動加票（沒開連線時預設打開）。
  • 「➕ 下一題」：這題結果存進右邊「本機紀錄」，可以匯出 CSV。

📝 測驗（題庫、出題、成績）

「📝 測驗」分頁的畫面和即時投票一樣（大黑板長條圖、QR code、學生手機作答），差別是：題目從題庫來、一定有答案、每題都記名計分，可以下載成績與排行榜。即時投票分頁則只做不計分的意見調查。

匯入題庫

「📝 測驗」分頁右側「📚 題庫 → 📂 匯入題庫」，可以選 Word（.docx）、Excel（.xlsx）、CSV 或文字檔，也可以直接貼上文字。匯入前會先列出讀到的題目讓你確認。

Word／文字檔照一般考卷寫法即可：

1. 下列何者是大型語言模型？
(A) Excel (B) ChatGPT (C) Word
答案：B

2. 哪些是 Google 的產品？
A. Gemini
B. Claude
C. NotebookLM
答案：AC

(X)3. 毛利率越高一定越賺錢。
  • 選項可以分行，也可以寫在同一行「(A)… (B)…」。
  • 答案寫在「答案：」後面，或用括號寫在題號前「(B)1.」、題號後「1.（B）題目」、題目最後「題目（B）」都可以（全形、小寫、括號內有空格也行）。括號裡的答案會從題目拿掉，學生看不到。答案有兩個以上字母＝多選題。題號前的空白括號「（　）」會自動拿掉；題目中間的填空括號會保留。
  • 沒有選項、答案是 O／X（或 是／否、對／錯）＝是非題。
  • 題號、選項用 Word 的自動編號也讀得到（第一層＝題目，第二層或另一組編號＝選項）。
  • 沒有選項也沒有是非答案的段落（例如標題、問答題）會略過，並列出來讓你知道。

Excel／CSV：欄位「題目、選項A、選項B…選項H、答案」，可以按「⬇ Excel 範本」下載範本來填。

答案會一起存進題庫

  • 匯入時讀到的答案（「答案：」、題號前的「(B)1.」、Excel 的「答案」欄）會一起存進題庫，出題時自動帶入，用來計算答對題數。匯入前的預覽會告訴你「有答案幾題、沒讀到答案幾題」。
  • 題庫卡上方顯示「✔ 有答案 N 題・⚠ 未設答案 M 題」；沒答案的題目不計分，可以按該題的「✏ 答案」補上。
  • 「➕ 手動新增一題」：輸入題目、選項（空白＝是非題）、答案（B、AC、O、X），直接加進題庫。
  • 出題時才按「✔ 設定答案」補的答案，也會寫回題庫，下次出同一題就有了。
  • 截止後如果有答案，大黑板會顯示「✔ 答對 N 人・✘ 答錯 M 人」。

出題

✋ 手動出題：按「▶ 出下一題」或某一題的「▶ 出這題」，題目、選項、答案會自動帶入並開始投票。截止後學生手機會顯示答對或答錯。

⏱ 自動出題：題庫卡切到「自動出題」，設定「每題作答」秒數與「公布答案停留」秒數，按「▶ 開始自動出題」。之後每一題會：出題 → 倒數 → 時間到自動截止 → 公布長條圖與答案（學生手機顯示答對／答錯）→ 停留幾秒 → 自動出下一題，直到題庫出完。

  • 「全班都作答完就提早截止」：連線的學生都答了就不用等倒數。
  • 「作答時先隱藏結果」：倒數時黑板只顯示已作答人數，截止才公布長條圖，避免跟著多數選。
  • 大黑板上方會顯示「⏱ 剩 N 秒」或「公布答案・N 秒後下一題」。過程中可以「⏸ 暫停」「▶ 繼續」「⏹ 停止自動」。
  • 中途老師自己按「截止」「下一題」「重新開放」或某題的「出這題」，就會切回手動。

成績與排行榜

  1. 學生加入時已經輸入學號或姓名；成績會依班級名單對應成同一個人（輸入姓名也能對到學號）。
  2. 每題截止後按「➕ 下一題」（自動出題會自己換題），結果就記進「本次測驗」的成績。
  3. 右側「🏆 本次測驗成績」按「⬇ 成績 CSV」或「⬇ 成績 Excel」。上半部每位學生一列：每題「✔ 答對（B）／✘ 答錯（C）／未作答」、答對題數、答錯題數、未作答題數、總題數、得分（百分制），依答對題數排序；下半部每題一列：正確答案、答對／答錯人數、答對率，以及答對名單、答錯名單（附選了什麼）、未作答名單。
  4. 「🏅 排行榜」可以投影前十名（同分同名次，名字照「投影時顯示」設定）。
  5. 「🆕 開始新測驗」：開一場新的測驗（成績另外計、題庫從頭出）。之前的測驗列在下方，可以再下載。匯入新題庫時，如果這場還沒有成績，會自動用題庫名稱當測驗名稱。
只有有設定答案的題目會算成績。學生輸入的學號或姓名會用目前選的班級名單對應；對不到的標「名單外」。名單裡沒作答的學生也會列出（0 分）。
測驗不是匿名：學號會經轉播站送到老師電腦。成績檔有學號、姓名與作答，請依個資規定保管。這是課堂練習用，不適合正式考試（沒有身分驗證，學生可以輸入別人的學號）。

手機連線原理

這個網站放在 GitHub Pages，是純靜態網頁，沒有自己的資料庫。投票與手機搶答借用作者為「創業島」架設的即時轉播站（Cloudflare Worker），每個代碼是一個獨立房間：

  • 老師電腦把「現在第幾題、幾個選項、開放或截止」這類代碼送進房間。
  • 學生手機送的是「選了 B」這樣的代號加上自己輸入的學號或姓名，只送到老師電腦，其他學生收不到，也看不到彼此的作答。
  • 每個代碼有一把老師金鑰，別的電腦或瀏覽器不能冒充老師；被占用時網頁會自動換新代碼。
  • 轉播站只負責轉送，不儲存作答；只有教室密碼與老師金鑰會暫存，最後一人離開就刪除。計票在老師電腦上進行，結果只存在老師的瀏覽器。
  • 轉播站會過濾不雅字詞與網址，並限制每人送訊息的頻率。

常見問題

學生掃了 QR code 打不開？

確認學生手機有網路。QR code 一律指向線上版網址；如果老師是用本機檔案開啟，學生仍會連到線上版，代碼一樣有效。

連線人數比實際人數多？

同一位學生用兩個瀏覽器開，會算兩人；關掉的分頁過一會兒才會離開。以「已作答人數」為準。

為什麼沒有聲音？

瀏覽器規定要先在頁面上點一下才能發聲。另外檢查「⚙ 常用設定 → 音效」和電腦音量。

可以用來考試計分嗎？

不建議。這是課堂互動用的匿名投票，沒有身分驗證，換瀏覽器就能再投一次。

換電腦上課？

舊電腦「⚙ 常用設定 → 資料備份 → 下載備份檔」，新電腦「從備份檔還原」。

隱私與限制

  • 名單、分組、投票紀錄、設定都只存在這台電腦的瀏覽器，清除瀏覽器資料就會不見。
  • 投票與手機搶答需要網路，會經過作者架設的轉播站（只轉送代碼與暱稱、不儲存）。
  • 學生加入時要輸入學號或姓名，老師電腦知道誰投了什麼（大螢幕不顯示個人作答）。沒有身分驗證，學生可以輸入別人的名字，不適合選舉、正式考試或需要防作弊的場合。
  • 上傳的名單、題庫檔案只在這台電腦的瀏覽器裡讀取，不會上傳。
  • 知道代碼（與密碼）的人都能進房間。下課按「🚪 關閉教室」，舊網址與 QR code 就失效；也可以設密碼。
  • 抽籤與分組用瀏覽器的安全亂數（crypto.getRandomValues），結果無法事後重現，需要紀錄請截圖或複製。
